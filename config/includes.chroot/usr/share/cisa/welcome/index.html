Where are the tools?

Open the Start menu, then CISA Tools. Tools are grouped in the order you'll usually use them. Command-line tools open a terminal showing what the tool does and how to use it.

Connect to the training labs

  1. Log in to the platform and download your VPN file (.ovpn): TryHackMe · OffSec
  2. Click the network icon in the system tray, then Configure Network Connections, then +, then Import VPN connection, and pick the file.
  3. Switch the VPN on from the network icon. That's it.

Ground rules

  • Only test systems you own or have written permission to test. That means the lab platforms above, CISA's own labs, and your own VMs.
  • Scanning or attacking anything else, including the campus network, is illegal and against university policy, even "just to see".
  • Not sure if something is allowed? Ask an e-board member first.

Keep it on your computer

Right now you're running from the USB/ISO, and anything you save is lost when you reboot. To install, double-click Install CISA Linux on the desktop. It can sit alongside Windows (you choose which one to start each time you power on). You can also install it in VirtualBox if you'd rather not touch your Windows drive.

Keep it updated: open Discover and click Update All, or run sudo apt update && sudo apt full-upgrade.
